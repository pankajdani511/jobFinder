# JobFinder

A simple and responsive job search website built using HTML, CSS and JavaScript.

JobFinder allows users to browse job opportunities, search and filter jobs, view job details, save interesting jobs and simulate applying for jobs.

---

## 🚀 Features

- 🔍 Search jobs by job title or keyword
- 📍 Search jobs by location
- 🏷️ Filter jobs by job type
- ↕️ Sort jobs by salary and recent posts
- ❤️ Save jobs
- 💾 Store saved jobs using LocalStorage
- 🔐 User Signup
- 🔑 User Login
- 🚪 User Logout
- 👤 Display logged-in user's name
- 📱 Responsive design for different screen sizes

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
